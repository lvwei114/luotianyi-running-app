# 界面精简调整（已包含在 v0.1.6）

按 2026-10-09 更新后的《下一步.txt》执行，替代此前同名文件中的需求。

1. 首页删除“本周记录”卡片及其历史入口；周统计继续在记录页展示。
2. 底部导航栏“跑步”改为“记录”。首页开始训练仍打开独立跑步界面。
3. 跑步中删除“定位与步幅”和“总步数／平均步频”卡片。计步、GPS 记录及原有计算逻辑保留；在记录与分析页、记录详情查看平均步频和步幅。
4. 记录详情的“删除这条记录”改为铺满内容区宽度的红色按钮（#E53935、白字、最小高度 48dp），保留二次删除确认。
5. 设置页删除“数据保存与迁移”卡片及其文件选择器。
6. 设置页删除副标题“按你的习惯调整”和说明“关闭鼓励语仍保留阶段和运动控制提示，补水独立设置。”。

后续已按方案 B 增加首页问候语、昵称和右侧连续天数，并将火焰图标替换为用户提供的 icon1.png；当前图集包含这些更新，详见 [首页问候语改进说明](首页问候语改进说明.md)。

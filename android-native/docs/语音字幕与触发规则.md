# 天依语音字幕与触发规则

共 59 条本地 WAV。字幕依据原项目语音脚本、本地 Whisper small/medium 转写对照整理，中文同音误识别和含糊发音按语境校正，尚未进行人工听审。标点与数字书写统一，不改动录音。字幕、试听与系统 TTS 兜底使用同一份 VoiceCatalog。

## 播报规则

- 复用 chatFrequency：关闭、稀疏 90–140 秒、标准 35–55 秒、密集 18–30 秒；继承原有用户设置。
- 早段先选开场聊天，中段穿插聊天与鼓励，接近结束选坚持类语音；冲刺选短句，放松不催促冲刺。
- 重要播报后随机语音至少留出 12 秒，正在说话时不积压随机语音；阶段切换替换尚未播放的旧阶段提示，提醒按时效丢弃。
- 运动前、途中、结束后补水均遵循补水开关，途中保留 15/20/30 分钟间隔及高温缩短 25% 的规则。
- 新鲜有效心率达到 90% 时播一级提醒，每 60 秒至多一次。达到 100% 持续 15 秒时保留原自动暂停逻辑：低于 110% 播二级，110% 及以上播三级。
- 提醒后有效心率低于 85% 并持续 15 秒时播恢复语音；暂停期间仍可提示恢复，但不自动恢复训练。缺失心率不会推测恢复。
- 60、90 分钟提醒各一次；120 分钟播放两小时提醒，之后每 30 分钟只使用不带具体时长的 time_long_a。过期超过两分钟的时长提醒不补播。
- 手动结束确认前，在运行且心率未偏高时使用 skip_cooldown 或 chat_end_a 建议先慢走；chat_end_a 也可在放松阶段使用，不在已结束后说准备结束。不新增跑法、不强制追加训练时间。
- 结束后依次播放完成、已启用的补水和聊天。关闭随机频率会关闭途中聊天及结束聊天，仍保留控制、阶段和已启用的提醒。
- 设置中的分类试听覆盖全部 59 条，训练期间禁用试听。字幕在实际播放开始时显示，结束后保留 1.2 秒，长句完整换行，浮窗保持固定在上方。

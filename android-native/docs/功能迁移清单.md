# 功能迁移清单

Kotlin + Jetpack Compose 原生实现已完成，源码位于仓库 `android-native/`，名称为“洛天依陪跑”。

| 模块 | 状态 |
|---|---|
| 四页导航、深色背景、内置背景图库 | 已实现，含 390×844/360×640 JVM 截图 |
| 引导/跟随/自定义跑 | 已实现，跟随心率滞回与 BPM 渐变，自定义 60–220 BPM |
| 定时跑 | 已实现，5–60 整分钟、暂停冻结、独立阶段、循环音乐 |
| GPS、计步、锁屏、后台恢复 | 已实现，记录距离只来自 GPS_PROVIDER |
| 平均配速/步频/步幅、历史和周统计 | 已实现，GPS 无效或无配对步数显示 `--` |
| 批量导入/歌单/音乐播放/BPM | 已实现，部分失败、重试、MediaSession、智能选曲 |
| 语音、节拍器、音量和提醒 | 已实现，内置 wav 优先，TTS 回退 |
| 标准 BLE 心率与告警 | 已实现，十秒过期、通知重试和断开恢复 |
| 个人资料、头像、背景、首页问候 | 已实现，首页按本地时间更新问候语和连续跑步天数 |
| 设置导入导出与旧版迁移 | v0.1.6 已移除设置页入口，底层历史实现保留 |

当前测试包版本为 `0.1.7-native-test`（versionCode 8），通过 GitHub Releases 分发。v0.1.6 的 39 项 JVM/Robolectric 测试通过，Lint 0 错误、17 条提示；v0.1.7 仅更新文案和版本号，编译、打包与签名校验通过，未重复运行测试。此前版本获维护者真机验证反馈，v0.1.7 尚需真机复测。详见 [原生版 README](../README.md)。

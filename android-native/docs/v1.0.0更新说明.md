# v1.0.0 更新说明

- 版本名更新为 `1.0.0`，versionCode 为 10，去掉版本名和 APK 文件名中的 `native-test`／原生测试版标记。
- 设置页版本号读取构建配置，修复此前仍显示 0.1.7 的问题。
- 定时跑整合进首页“今天怎么跑？”，选中后显示 5～60 分钟设置；去掉滑动条刻度点和末端圆点，删除“暂停不计时，到点结束”提示。
- 首页首次未跑显示 icon0 和“快去跑步吧！”。连续 1～3 天用 icon1，4～7 天用 icon2，8 天及以上用 icon3；漏掉一个完整自然日后使用 icon4，重新完成训练后从第 1 天开始。
- 每连续 5 天显示 icon5 祝贺弹窗。同一天多次训练只计一天，同一连续周期的同一个里程碑确认后不重复提醒。
- 首页图标调整为 42dp，弹窗图标为 200dp，提供五种屏幕密度的高清缩略图与轻度锐化；“继续加油”按钮放大并居中。
- 使用维护者提供的绿色洛天依跑步标志作为应用图标，适配传统与自适应启动图标。

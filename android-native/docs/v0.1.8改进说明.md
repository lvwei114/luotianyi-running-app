# v0.1.8 原生测试版

版本 `0.1.8-native-test`，versionCode 9，应用名“洛天依陪跑”，支持 Android 8.0 及以上。

## 主要改进

- 全部 59 条本地语音接入情境播报和字幕目录，提供分类试听；字幕随实际播放开始显示，长句完整换行。
- 继续使用现有随机鼓励语频率设置，根据运动阶段、补水、心率提醒和运动控制选择语音；通过优先级、过期时间和播放回调处理排队，避免过时提示和字幕错配。
- 引导跑和定时跑热身 BPM 从 100–115 提升到 150–160；后续阶段依次为 160–170、170–175、175–150。保留原有阶段名称、时间占比和 175 BPM 峰值。
- 使用连续端点和平滑插值衔接阶段；切换跑法从当前 BPM 过渡，避免进入心率跟随跑时突然回到 150。内部过渡速度最多 2.5 BPM/秒。
- 保留定时跑 5–60 分钟、暂停冻结计时、GPS 距离统计、自定义跑和现有心率联动规则。

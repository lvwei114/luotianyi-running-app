# v0.1.2 原生测试版改进

根据 2026-10-08 的文本文档及后续补充完成。

| 内容 | 修改 |
|---|---|
| 背景图片无法添加 | 修复尺寸预读返回 null 被误判为失败的问题。自选背景与头像共用流程均可导入，仍保留缩小、EXIF 方向校正、私有目录保存及失败提示。 |
| 天依说 | 改为屏幕上方固定的半透明圆角浮窗，显示“天依：…”；播放时出现、结束时淡出。不可拖动，不需要系统悬浮窗权限。 |
| 跑步导航 | 底部“跑步”页展示记录及分析；首页开始训练、服务确认会话后打开独立跑步界面。收起/返回不会结束训练，首页及记录页提供返回训练入口。训练完成后显示总结并返回记录页。 |
| 跑步界面 | 距离和运动时间使用大号独立展示区域；保留 GPS 预热、四种跑法、音乐、心率、暂停与结束控制。顶部预留语音浮窗空间。 |
| 记录分析 | 显示累计训练次数、距离、运动时间、平均配速、平均步频、步幅、本周每日运动时间及连续天数。按总测量值计算，不直接平均每次指标；无测量保持“--”。 |
| 动画 | 原生实现原项目的橙色/蓝色浮动光晕、上升粒子、页面淡入淡出。完整模式训练时播放装饰动画；简洁模式保留静态光晕，省电模式关闭装饰与页面动画。应用离开前台停止装饰动画。 |
| 颜色与文案 | 蓝色强调色统一为 #66CCFF，包括 Material 主题默认容器及控件颜色。界面“GPS 距离”改为“距离”，“GPS 平均步幅”改为“步幅”，移除“不改变原有三种跑法”。GPS-only 记录规则保持。 |

验证：32 项 JVM/Robolectric 测试全部通过，编译通过，Lint 0 错误、11 条提示；检查 390×844 和 360×640 界面截图，包含独立训练界面及顶部浮窗。新增覆盖 content URI 图片导入、大图缩小、头像 EXIF 旋转、坏图片拒绝、加权统计、训练收起/返回、浮窗位置和生命周期。

2026-10-08，维护者反馈已完成真机验证，未发现问题；未提供机型和系统版本。测试 APK 使用调试签名，应用名称为“洛天依陪跑”，versionCode 3，versionName 0.1.2-native-test，支持 Android 8.0 及以上。

打包与校验通过：`releases/洛天依陪跑-原生测试版-v0.1.2.apk`（44,437,701 字节）。apksigner 验证 v2 签名成功，aapt2 确认应用名称及版本；发布文件与构建产物 SHA256 一致，校验值保存在 `releases/SHA256SUMS.txt`，v0.1.1 原包保留。

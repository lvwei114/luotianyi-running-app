# v0.1.6 原生测试版

- 首页删除“本周记录”卡片，底部“跑步”导航改为“记录”。
- 跑步中删除定位、步幅及总步数／平均步频卡片；记录页保留步频、步幅和统计分析，计算逻辑保持。
- 记录详情的删除操作改为内容区通栏红色按钮，保留删除确认。
- 设置页删除“数据保存与迁移”模块、顶部副标题和鼓励语说明文字。
- 首页使用随手机本地时间变化的问候语和设置昵称，右侧显示连续跑步天数。同一天多次训练只计一天；今天没有记录时保留截至昨天的连续天数。
- 右侧使用用户提供的 icon1.png，按确认后的回退版本显示为 28dp，资源为 128×128 透明图片。
- 保留 v0.1.5 的 GPS 静止配速修复、距离与配速同字号、作者信息及应用图标。

版本 `0.1.6-native-test`，versionCode 7，支持 Android 8.0 及以上，使用与此前测试包一致的调试签名。

编译、39 项 JVM/Robolectric 测试、Lint 和 assembleDebug 通过，Lint 0 错误、17 条提示。APK 应用名“洛天依陪跑”、版本及 v2 签名校验通过，证书与 v0.1.5 一致。
